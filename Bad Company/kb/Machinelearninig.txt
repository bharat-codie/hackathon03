Machine Learning Knowledge Base

Here is a structured database of key concepts in machine learning. Each entry has a name, a simple definition, and sometimes examples / why it matters.

1. What Is Machine Learning (ML)

Definition: Machine Learning is a branch of computer science where we teach computers to learn from data, instead of giving them explicit rules.
Example / Why It Matters: Rather than writing a rule like “if x > 5 then …”, a machine learning model looks at lots of past data and figures out patterns (for example, predicting house prices).

2. Data / Dataset

Definition: Data is a collection of information (numbers, text, images, etc.) that we feed into machine learning models. A dataset is a structured form of data often split into examples (“rows”) and features (“columns”).
Example: A dataset for predicting house prices might have features like “size of house”, “number of rooms”, “location”.

3. Features

Definition: Features (also called input variables) are the parts of the data that the model uses to learn. They are like the “ingredients” for making predictions.
Example: In a dataset about cars, features might be engine_size, weight, horsepower.

4. Labels / Target

Definition: A label (or target) is the correct answer that we want the model to predict. In supervised learning, each example in the dataset has a label.
Example: In a spam-detection system, each email might be labeled “spam” or “not spam”.

5. Model

Definition: A model is what the machine “learns.” It’s a mathematical representation of the pattern discovered in the data.
Example: A linear regression model learns a straight-line equation to predict a number (like price) from input features.

6. Training

Definition: Training is the process of teaching the model by showing it examples (the dataset). During training, the model adjusts itself to reduce the error between its outputs and the actual labels.
Why It Matters: Without training, the model doesn't know how to predict — it just starts with random parameters.

7. Prediction / Inference

Definition: After a model is trained, prediction (or inference) is when we give the model new data and ask it to predict the output.
Example: Using a trained house-price model to guess the price of a new house.

8. Supervised Learning

Definition: A type of machine learning where the training data has both inputs (features) and correct outputs (labels). The model learns to map input to output.

9. Unsupervised Learning

Definition: A type of machine learning where the data has no labels. The model tries to find patterns or structure on its own. 
Wikipedia

Techniques:

Clustering: Grouping similar data points together (e.g., K-means). 
GeeksforGeeks

Dimensionality Reduction: Simplifying data by reducing the number of features (e.g., PCA). 
Wikipedia

Why It Matters: Useful when we don’t have labeled data, but want to explore or compress data.

10. Reinforcement Learning

Definition: A learning method where an “agent” interacts with an environment, takes actions, and receives rewards or penalties. Over time, the agent learns which actions give good rewards.
Why It Matters: Very useful in decision-making tasks, like games, robotics, or any scenario where the system has to plan.

11. Feature Learning (Representation Learning)

Definition: Techniques that let the model automatically discover useful features (representations) from raw data, instead of relying on manual “feature engineering.” 
Wikipedia

Why It Matters: It makes models more powerful, especially for complex data like images or text.

12. Overfitting

Definition: When a model learns the training data too well, including its noise and random quirks, and so it performs poorly on new, unseen data.

Why It Matters: Overfitted models don’t generalize — they “memorize” rather than “understand.”

13. Underfitting

Definition: When a model is too simple to capture the underlying pattern in the data. It performs badly on both training data and unseen data. 
GeeksforGeeks

Why It Matters: Means the model is not learning enough; it’s not flexible or complex enough to capture the true relationships.

14. Regularization

Definition: Techniques used to prevent overfitting by adding a penalty for complexity (e.g., penalizing large weights). 
Wikipedia

L1 Regularization (Lasso): Penalizes absolute values of weights.

L2 Regularization (Ridge): Penalizes square of weights.

Early Stopping: Stop training when performance on a validation set starts to worsen.

15. Structural Risk Minimization (SRM)

Definition: A principle in ML which balances two things: (a) how well the model fits the training data, and (b) how complex the model is. The goal is to minimize both error on training and the risk of overfitting. 
Wikipedia

Why It Matters: Provides a theoretical foundation for “good” model selection and generalization.

16. Early Stopping

Definition: A regularization method where during training you monitor performance on a validation set, and when it starts to worsen, you stop training. 
Wikipedia

Why It Matters: Prevents the model from overfitting by not training “too much.”

17. Training / Validation / Test Split

Definition:

Training set: Data used to train the model.

Validation set: Data used to tune hyperparameters / monitor performance during training.

Test set: Data used to evaluate the final model’s performance.
Why It Matters: Helps ensure that the model generalizes well and isn’t just tuned to one set.

18. Loss Function / Cost Function

Definition: A mathematical way to measure how “wrong” the model’s predictions are compared to the true labels. During training, models try to minimize this loss. 
GeeksforGeeks

Examples: Mean Squared Error (for regression), Cross-Entropy Loss (for classification).

19. Hyperparameter

Definition: Settings for a model that are chosen before training, not learned from data. These are things like learning rate, number of layers, or how strong regularization is.
Why It Matters: Choosing good hyperparameters can make a big difference in model performance.

20. Parameter

Definition: The internal variables learned by the model during training (e.g., weights in a neural network). 
Google for Developers

Why It Matters: These determine how the model converts inputs to predictions.

21. Generalization

Definition: The ability of a model to perform well on new, unseen data, not just the data it was trained on.
Why It Matters: A model with good generalization is useful in real-world situations.

22. Bias-Variance Tradeoff

Definition: A fundamental challenge in ML:

Bias is error due to overly simple assumptions (underfitting).

Variance is error due to too much complexity / sensitivity to training data (overfitting).
Why It Matters: You want a balance — not too much bias, not too much variance.

23. Cross-Validation

Definition: A technique to reliably evaluate model performance. You split the data into “folds” (e.g., 5 parts), train on some folds, validate on others, and rotate.
Why It Matters: Gives a more accurate picture of model performance than a single train/test split.

24. Bagging (Bootstrap Aggregating)

Definition: A technique to reduce variance: train multiple models on different random subsets (“bootstrap” samples) of the data, then average (or vote).
Why It Matters: Helps make predictions more stable and robust.

25. Boosting

Definition: A method where multiple weak models are trained sequentially, each trying to fix the errors of the previous ones.
Why It Matters: Very powerful ensemble technique (e.g., AdaBoost, Gradient Boosting) — can give strong predictive models.

26. Support Vector Machine (SVM)

Definition: A supervised learning algorithm that tries to find the “best boundary” (hyperplane) that separates different classes.
Why It Matters: Works well for classification, especially when data is not too big and is well-separated.

27. Neural Network

Definition: A model inspired by the brain: made up of “neurons” (nodes) organized in layers that transform input into output via learned weights.
Why It Matters: Very flexible; can model highly complex relationships, such as in images, text, and speech.

28. Deep Learning

Definition: A sub-field of neural networks where the network has many “hidden” layers (deep architecture). This helps learn very rich, complex patterns.
Why It Matters: Powers modern AI like image recognition, voice assistants, etc.

29. Dropout

Definition: A regularization technique for neural networks: during training, randomly “drop” (turn off) some neurons in each step, so the network doesn’t rely too heavily on any single one. 
Google for Developers

Why It Matters: Helps prevent overfitting in deep networks.

30. Precision

Definition: A metric (for classification) that tells us how many of the predicted “positive” cases are actually positive. 
GeeksforGeeks

Why It Matters: Useful when the cost of false positives is high.

31. Recall (Sensitivity)

Definition: A metric that tells us how many of the actual “positive” cases the model correctly predicted. 
GeeksforGeeks

Why It Matters: Important when missing a positive case is very costly (e.g., in disease detection).

32. ROC Curve / AUC

Definition:

ROC Curve: A graph plotting true positive rate vs false positive rate at different threshold values. 
GeeksforGeeks

AUC (Area Under Curve): A number that sums up the ROC curve: how good the model is overall.
Why It Matters: Helps compare classification models beyond just “accuracy.”

33. Dynamic / Online Learning

Definition: Learning that happens continuously or frequently, rather than once. A dynamic (or online) model updates as new data comes in. 
Google for Developers

Why It Matters: Useful when data arrives in a stream (e.g., live user behavior, sensor data).

34. Dropout Regularization (again)

Definition: (See “Dropout” above.) Specifically, in neural networks you randomly disable a subset of neurons in each training iteration. 
Google for Developers

35. Positive Class / Negative Class

Definition:

Positive Class: The class you are especially interested in detecting (e.g., “fraud” in fraud detection). 
Google for Developers

Negative Class: The other class(es) — e.g., “not fraud.”
Why It Matters: Many evaluation metrics (like precision, recall) depend on which class you call “positive.”

36. Proxy Label

Definition: When you don’t have the exact label you want, you use another related label (a proxy) to train your model. 
Google for Developers

Example: Suppose you want to measure “happiness” in a dataset, but you don’t have happiness scores. You might use “frequency of smiling photos” as a proxy label.

37. Structural Risk vs Empirical Risk

Definition:

Empirical Risk: The error (loss) on the training data.

Structural Risk: Combines empirical risk + a penalty for model complexity (to avoid overfitting). This is part of the SRM principle. 
Wikipedia

Why It Matters: Models that minimize only empirical risk tend to overfit; SRM helps prevent that.

38. Statistical Learning Theory

Definition: A theoretical framework that studies how and why machine learning algorithms work, especially in terms of making predictions from data.
Why It Matters: Provides the mathematical foundation for generalization, overfitting, risk, and capacity of models.

39. Big Data in ML

Definition: Very large datasets (in volume, variety, velocity) that traditional data-processing tools find hard to handle.
Why It Matters: ML often benefits from big data: more data helps models learn better, but also introduces challenges (storage, computation).

40. Evaluation Metrics (General)

Definition: Ways to measure how good your model is. Depending on the task, different metrics are used.
Common Metrics: Accuracy, Precision, Recall, F1-Score, AUC, Mean Squared Error.
