📘 College Website with Subject-Specific Chatbot

Welcome to my project repository!
This project contains a **College Website** integrated with a **Subject-Specific Chatbot** built using **Python**, **Flask**, and **ChatterBot**.

The chatbot is designed to help students by answering queries related to different subjects, making the college website more interactive and helpful.

---

## 🚀 Features

* Full **College Website UI**
* **AI-powered Chatbot**
* Subject-specific query handling
* Built using Python & Flask
* Easy to install & run

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JS
* **Backend:** Python (Flask)
* **Chatbot Engine:** ChatterBot
* **ML Libraries:** NumPy, scikit-learn

---

## 📦 Installation & Setup

### 🔧 Requirements

You will need **Python 3.12.0**
Use **VS Code** (recommended)

### 📥 Install Dependencies

Open a **new terminal** and run:

```
pip install flask
pip install chatterbot
pip install numpy
pip install flask-cors
pip install sklearn
```

⚠️ **IF sklearn gives an error**, then run this instead:

```
pip install scikit-learn
```

(You can add any other library you used)

---

## ▶️ How to Run the Project

```
python app.py
```

Open browser and go to:

```
http://127.0.0.1:5000
```

Your College Website + Chatbot will start running 🎉
